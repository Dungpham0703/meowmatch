SAME QUERY. DIFFERENT WAYS TO MATCH.

Two ways to find
your kind of cat.

01 / Keyword Search
Matches words in meme names, captions, tags, and visual descriptions. Try something literal, like “cat wearing sunglasses”.
02 / Image Semantic Search
Compares your query embedding with embeddings created directly from meme images. The ranking uses the images themselves, without their captions.

Both methods search the same collection. Image semantic search uses the same model for queries and images. The nearest match may still miss your intended mood.
